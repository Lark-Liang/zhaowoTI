## 忘川风华录 - 性格测试网页

> 照我TI测试 - 测测你是忘川雅社的谁？

### 项目简介

这是一个基于网页的测试，灵感来源于「忘川风华录」游戏中的雅社“照我汉衣冠”的QQ群。通过48道题目，从8个维度评估你的性格，并匹配最相似的雅社成员。特殊规则等均结合题目及选项内容，依据雅社群聊中各人的真实表现制定。

### 测试维度

| 维度 | 说明 | 得分范围 |
|------|------|----------|
| XP光谱 | 角色颜值偏好程度 | -12 ~ +12 |
| Impart参与度 | 活动参与积极性 | -12 ~ +12 |
| 梗图制造力 | 玩梗和整活能力 | -12 ~ +12 |
| 金戈血压指数 | PVP竞技热情 | -12 ~ +12 |
| 氪金理智值 | 充值消费倾向 | -12 ~ +12 |
| 雅社归属感表达 | 社团活跃度 | -12 ~ +12 |
| 名士专情度 | 角色忠诚度 | -12 ~ +12 |
| 水群作息相位 | 在线活跃时间 | -12 ~ +12 |

### 匹配角色

共包含 **13个角色**：冰鲜、熏猪肉、嫂子、糊纸、旅游金箔厂、善舞零、燃烧红利群等。

### 技术栈

- **HTML5** - 页面结构
- **CSS3** - 深色国风主题样式
- **JavaScript ES6+** - 测试逻辑和交互

### 功能特点

1. **选项随机化** ⭐
   - 每次开始测试时，所有题目的选项顺序都会随机打乱
   - 使用 Fisher-Yates 洗牌算法确保公平随机
   - 同一测试会话中返回上一题时选项顺序保持一致

2. **实时进度** - 显示答题进度和百分比
3. **特殊规则** - 特定选项可增加与特定角色的匹配度
4. **相似角色推荐** - 显示80%以上匹配度的其他角色
5. **响应式设计** - 支持桌面和移动端

### 运行方式

直接在浏览器中打开 `index.html` 文件即可运行。

```bash
# 方式1：双击打开
open index.html

# 方式2：使用本地服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```

### 计分规则

每道题有4个选项，对应得分：
- **A选项**: +2分
- **B选项**: -2分  
- **C选项**: +1分
- **D选项**: -1分

### 特殊匹配规则

| 题目 | 选项 | 角色 | 加成 |
|------|------|------|------|
| T3_4 | D | 冰鲜、熏猪肉 | +4 |
| T4_5 | B | 嫂子 | +7 |
| T6_3 | C | 熏猪肉 | +5 |
| T6_6 | D | 熏猪肉 | +5 |
| T8_5 | D | 糊纸 | +5 |

### 相似度算法

使用**欧几里得距离**计算用户得分与角色模板的相似度，距离越小相似度越高。
